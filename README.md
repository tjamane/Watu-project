# Watu Healthcare App

This is a comprehensive React Native Expo mobile application for a Namibia-based healthcare appointment system. It features a dual-role authentication system (Patient and Doctor), robust navigation, a dynamic search and filtering system for doctors, and functional appointment booking logic.

## Version
Current Version: **1.0.0**

## Prerequisites
Before you begin, ensure you have the following installed:
- [Node.js](https://nodejs.org/) (which includes npm)
- [Git](https://git-scm.com/)
- Expo Go app on your iOS or Android device (for physical device testing)

## Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/tjamane/Watu-project.git
   cd Watu-project
   ```

2. **Install dependencies:**
   Using npm:
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm start
   ```
   Or explicitly using Expo:
   ```bash
   npx expo start
   ```

## Running the App

Once the development server is running, you'll see a QR code in your terminal.
- **Android:** Scan the QR code with the Expo Go app.
- **iOS:** Open the default Camera app and scan the QR code, then tap the prompt to open in Expo Go.
- **Web:** Press `w` in the terminal to open the web version in your browser.
- **Emulators:** Press `a` for Android emulator or `i` for iOS simulator (ensure they are configured and running beforehand).
